# 当前进度

更新时间：2026-08-02

## 已完成

- 已将多传输与 SoftAP 配网功能合入 `main`，并修复配网页面持续显示“正在扫描”但无法选择网络的问题：扫描结果使用可选下拉框展示，支持重新扫描、15 秒超时提示和手动输入 SSID。
- 已实现复合 BLE HID 键盘和鼠标报告，并将鼠标报告同步升级为 7 字节格式。
- 串口协议升级到 v2：鼠标 X/Y 使用小端有符号 16 位，主机、固件、Target Agent 和协议文档已同步。
- 主机端以 500 Hz 上限累计 Raw Input 鼠标位移，保留鼠标按钮转换顺序，避免高频原始事件逐帧挤压串口。
- 固件使用 64 位累计器保存待发送鼠标位移，控制事件使用独立队列；TinyUSB 完成回调用于统计实际完成的报告与位移。
- 已增加主机、输入会话和 USB HID 链路统计，包括输入/提交/完成数量与位移、积压、序号不连续、USB ready 状态、提交失败、完成延迟和完成间隔。
- 已修复 UART 接收卡顿：接收任务阻塞等待首字节后立即排空当前已到达的数据，不再等待凑满 256 字节。该问题原先会约每 16 个协议帧集中处理一次，造成鼠标先停顿再跳跃。
- 已增加主机鼠标检查程序，覆盖协议 v2 编解码、位移累计完整性、按钮转换顺序、500 Hz 发送节奏和停止转发后的禁止发送行为。

## 真实设备验证

已在串口、ESP32-S3、TinyUSB 和手机 USB Host 的真实链路上执行三组测试。每组以 20 ms 间隔发送 50 帧，分别为每帧移动 20、5、1：

| 每帧 X 位移 | 输入帧 | USB 有效提交/完成 | 期望总位移 | 实际完成总位移 |
|---:|---:|---:|---:|---:|
| 20 | 50 | 50 / 50 | 1000 | 1000 |
| 5 | 50 | 50 / 50 | 250 | 250 |
| 1 | 50 | 50 / 50 | 50 | 50 |

- 最大积压为 1 帧。
- USB 完成间隔约为 20–24 ms。
- 三组测试均未丢失位移，USB 提交与完成数量一致。
- 上述结果证明串口到手机 USB Host 的数据和节奏符合预期；手机界面上的最终视觉流畅度仍需用户实际移动鼠标观察确认，不能由链路统计替代。

## 后续必须完成

### 主机断开后的安全停止

主机进程、串口或网络输入连接断开后，系统必须：

1. 立即向当前输出后端释放所有键盘按键和鼠标按钮，清空待发送输入，避免目标设备卡键。
2. 停止 HID 模拟和输入转发，不得因残留会话、心跳恢复或自动重连而继续发送输入。
3. 连接恢复后保持停止状态；只有主机显式建立新的输入会话并恢复转发，才允许重新模拟键鼠。
4. 为主机正常退出、异常断线、串口重连、Wi-Fi 连接断开、租约超时、USB/BLE 后端切换分别增加验证，实际检查目标端按键和鼠标按钮均已释放，且断线期间没有后续 HID 报告。
