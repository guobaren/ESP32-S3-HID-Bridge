## 已完成项

+ 原生 USB 启动时根据 UART 有效协议帧选择 profile：检测到协议时枚举 `USB Keyboard with Touchpad` HID-only，否则枚举 `HID Bridge CDC` CDC-only。
+ CDC 模式收到晚到 UART 协议帧后会执行 `ReleaseAll` 并单次安全重启，下一次启动进入 HID-only。
+ USB HID 与 BLE HID 使用先连接锁定策略；活动链路断开时释放输入并切换到仍在线的输出，后连接链路不抢占。
+ BLE 名称为 `Keyboard with Touchpad`，并通过项目私有 NimBLE 兼容补丁避免外设主动远端特性交换导致的反复断连。
+ BLE 鼠标以 10 ms 节拍发送合并位移；发送任务固定到 Core 1、优先级 10，NimBLE 日志限制为 Warning。
+ 主机默认使用精简高性能日志。用户 A/B 确认完整日志模式是鼠标偶发卡顿的触发条件，精简模式下问题消失。

## 特殊指令

- 日常运行保持 `showDeviceLogInUi: false`；完整日志仅用于短时排障。
- 修改固件后运行 `idf.py set-target esp32s3` 和 `idf.py build`。
- 修改主机后运行 Release build 与 `dotnet format --verify-no-changes --no-restore`。
- 停止转发、断线、切换或退出时必须发送 `ReleaseAll`。
- 升级 ESP-IDF 时必须重新审查 NimBLE 兼容补丁的源码锚点和连接回调顺序。
- 固件刷写接口只允许本机请求；局域网远程控制应在目标机执行 `http://127.0.0.1:24815` 请求。
