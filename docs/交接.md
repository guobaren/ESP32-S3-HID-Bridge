## 当前目标

## 特殊指令

- 当前真实主拓扑：`Windows → USB-to-UART/原生 USB CDC → ESP32-S3 → USB HID/BLE HID → 目标设备`；UDP 仅注入主机既有鼠标报告链路，不取代串口传输。
- 不要把 Wi-Fi 实现删除；恢复前必须同时审查 `firmware/main/runtime_features.h` 与 `CONFIG_HID_BRIDGE_WIFI_ENABLE`，并重新完成安全和真实链路验收。
- UDP 默认监听 `0.0.0.0:24814` 且无身份认证；只能部署在受信任网络，必要时用 `remoteInputBindAddress=127.0.0.1` 或 Windows 防火墙限制来源。
- 根目录功能版 EXE 已于 2026-08-09 12:38:36 发布，354500 bytes，SHA-256 为 `3AC622F780C6F800DECDCB523801319F83EEE3663ECC1A40F891821D7C7F27F9`；当前未启动运行实例。
- 功能版备用发布物位于 `artifacts/mouse-recording-release/HidBridge.Host.exe`，最后写入时间为 2026-08-09 12:38:38，354941 bytes，SHA-256 为 `E372230CA40F82D61FEFAFE852249B3B81932F7BE77CCC687ECB367385A792D7`。
- UDP 平滑固定参数：统计窗 100 ms、主机目标 50 槽/窗、队列上限约 100 份；首窗无历史速率时直接发送。鼠标 5 秒统计日志会输出前窗接收数、参考速率、待发送份数和过载合并数。
- BLE 固件仍为 `BLE_MOUSE_SEND_INTERVAL_MS=10`；不要把主机 500 Hz 自动检查当作 BLE 500 Hz 输出证明。
