## 特殊指令

- 当前真实主拓扑：`Windows → USB-to-UART/原生 USB CDC → ESP32-S3 → USB HID/BLE HID → 目标设备`；UDP 仅注入主机既有鼠标报告链路，不取代串口传输。
- USB/BLE 输出采用先连接者锁定：状态灯只表示当前活动输出（USB 绿、BLE 蓝），后连接链路不得抢占；当前活动链路断开后才切换到另一条在线链路。
- USB 失活判定使用 HID `ready` 连续 100 ms 为假，而不是只看 `tud_mounted()`；该阈值用于过滤端点短暂忙碌，若后续真实设备出现误切换必须保留日志后再调整。
- 本次已烧录端口为 `COM4`；重复烧录命令：`. .\scripts\Enter-EspIdf.ps1; Set-Location .\firmware; idf.py -p COM4 flash`。端口号属于瞬时设备状态，后续烧录前仍需重新识别。
- 不要把 Wi-Fi 实现删除；恢复前必须同时审查 `firmware/main/runtime_features.h` 与 `CONFIG_HID_BRIDGE_WIFI_ENABLE`，并重新完成安全和真实链路验收。
- UDP 默认监听 `0.0.0.0:24814` 且无身份认证；只能部署在受信任网络，必要时用 `remoteInputBindAddress=127.0.0.1` 或 Windows 防火墙限制来源。
