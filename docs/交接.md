## 特殊指令与边界

- 不运行会移动鼠标、点击或调用真实 `SendInput` 的测试；纯逻辑检查可以保留。
- kmboxNet 暂不实现 `reboot/setconfig/setvidpid/lcd`；UDP 接口没有身份认证，只应在受信任局域网中使用。
- 日志写入 EXE 同目录的 `log/host`、`log/device`、`log/automation`；三类数量配置分别为 `hostLogRetentionCount`、`deviceLogRetentionCount`、`automationLogRetentionCount`，范围 `1..1000`。
- 驱动安装/卸载属于 UAC 和设备状态操作，只由用户确认后执行。
- 停止转发、断线、切换和退出必须释放已跟踪输入；局域网刷写 API 只应在受信任网络启用，刷写请求不传串口而使用对端设置页当前选择。
- 不删除或重置受保护的 `D:\ESP32-S3-HID-Bridge-worktrees\input-latency-telemetry`，不把备份 EXE 或 `artifacts/` 纳入提交。
