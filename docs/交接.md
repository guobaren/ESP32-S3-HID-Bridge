## 当前目标

修正 USB 输出错误依赖控制端 EXE/UART 握手的问题：固件始终以 USB keyboard/touchpad HID 启动，打开 EXE 不得改变 USB profile 或通过重启打断活动 BLE；其余 USB 优先、BLE 活动锁定规则保持不变。当前分支为 `main`。

## 已完成项

+ 原生 USB 启动时根据 UART 有效协议帧选择 profile：检测到协议时枚举 `USB Keyboard with Touchpad` HID-only，否则枚举 `HID Bridge CDC` CDC-only。
+ CDC 模式收到晚到 UART 协议帧后会执行 `ReleaseAll` 并单次安全重启，下一次启动进入 HID-only。
