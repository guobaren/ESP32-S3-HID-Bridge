## 已完成项

+ kmboxNet 的初始化、序号去重、16 字节 ACK、128 字节 `enc_*` 解密和端点会话管理已接入现有 UDP 服务器。
+ move/auto/bezier/wheel 统一进入 `TryInjectMouseMovement`；远端按钮和键盘完整状态进入现有 HID 报告泵，停止、重连和退出路径仍释放远端状态。
+ `trace` 可在线切换现有 UDP 平滑；切换前排空待发位移，避免丢失尾部。`monitor` 仅登记回传端点并发送 21 字节鼠标+键盘实体状态，不改变当前捕获状态。
+ `mask/unmask` 只过滤发往目标的实体输入，monitor 仍能观察原始实体按键；解除屏蔽时会安全恢复仍处于按下状态的实体键。
+ 左上角局域网监听地址布局和 kmboxNet 协议兼容均有自动化检查，README 与 `docs/protocol.md` 已同步。
