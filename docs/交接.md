## 当前目标

在 `firmware/dual_proxy` 同一镜像盲插自动角色的正常拓扑下，进一步面向多种 Logitech 鼠标自动适配：Mouse Host 动态采集 VID/PID、字符串和各 HID 接口 Report Descriptor，经有界 Profile 分片传给 PC Device；后续再由 PC Device 动态重枚举为一个物理鼠标并追加 CDC，按接口表透传 Input/Output/Feature。当前动态 Profile 观察链路已在 C092 实机通过，但 raw Device/Configuration descriptor、动态重枚举、完整控制传输和 Logitech 驱动识别尚未实现/验证；C092 仅是样本，不是固定配置。
