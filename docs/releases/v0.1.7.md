# v0.1.7 更新日志

## 新增

- 鼠标捕获页右上角分别显示 P 板和 M 板的 COM 口与当前波特率。两路状态分别刷新，旧版单板通路显示为“单板”。
- Host 的项目 UDP JSON 接口支持可选布尔字段 `left`。可单独发送 `{"left":true}` 或 `{"left":false}`，也可与位移、滚轮同包发送。省略字段保留现有左键状态，重复设置同一状态不会额外产生点击，非布尔值会拒绝整个报文。调用方控制点击时长与松开时机，Host 停止 UDP 监听时释放远端输入。

## 修复

- 已启用 Makcu 时，Host 在后台恢复模式。等待 M 板连接采用 5 秒预算，串口探测不再挡住主窗口。固件无法通过验证时保留用户配置，宏和 Lua 保持暂停。
- Host 启动失败时先清理串口和监听资源，再显示错误提示，避免停在错误窗口的旧实例继续占用两块板。
- 设置页启动卡片随可见选项调整高度。双板模式下，固件刷写区域紧接 Makcu 设置，旧版单板模式下按需展开 UDP 设置。
- 修复窗口缩小时捕获区域盖住输出灵敏度滑条的问题，最小窗口仍可完整显示滑块和刻度。修正右上角双行串口状态的高度。

## 移除与兼容性

- 移除 Host 的物理鼠标按键共享内存发布、对应设置与自动订阅。旧配置仍可加载，重新保存时会移除这两个旧字段。依赖 `HidBridge.Buttons.v1` 或自定义映射名的程序需要改用其支持的其他状态来源。固件继续支持 A5 串口 `ButtonState (0x1F)` 协议。
- 本版本的功能改动集中在 Host，双板固件源码与 v0.1.6 一致。已使用 v0.1.6 固件的设备可直接替换 Host。包内继续提供双板刷写清单与三段镜像、CH340/CH341 驱动和示例配置。
