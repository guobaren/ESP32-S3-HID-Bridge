- 真机 A/B（2026-09-25，真实设备）：「**移动把 IO 占满**」被**否证**——静止组与 1.1 kHz 移动组（58146 条）控制传输均为 `388/388` 成功、`ctrl_lat_max_us=8999`、`slow10=slow100=0`。
