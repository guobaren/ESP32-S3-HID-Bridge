## 新增审计项：窗口版捕获程序（2026-08-03）

### 需求边界

- 窗口上半区约占一半，显示鼠标同步锁定的中心停放位置和当前同步状态。
- 窗口下半区是只读、多行、可选择复制的日志输出栏。
- 界面始终显示 `HOME` 开启/关闭同步和 `END` 结束程序。
- 同步开启时，除两个控制快捷键外，其他键盘按键及组合键都必须发送到对端并拦截本机；鼠标固定在上半区中心，移动、按钮和滚轮只作用于对端。
- 同步关闭或进程退出时，恢复本机输入、解除鼠标锁定并发送 `ReleaseAll`。

### 当前证据与限制

- `host/HidBridge.Host/Program.cs`：WinForms 主窗体与日志重定向已实现；尚缺真实设备在线时的桌面输入证据。
- `host/HidBridge.Host/Input/InputForwarder.cs`：HOME/END 控制键、同步强制拦截、Ctrl/Alt 即时报告和停止清理已实现。
- `host/HidBridge.Host/Input/MouseCursorLock.cs`：已使用 `ClipCursor`/`SetCursorPos`，但尚未在开发板在线时取得真实裁剪矩形证据。
- 当前限制：真实 USB/BLE 目标输入、退出后的实测 `ReleaseAll` 和鼠标裁剪解除仍待硬件/桌面验收。

### 下次验收证据要求

1. Release 构建和发布目录实际存在 GUI EXE，进程无控制台窗口。
2. 实际打开窗口，读取控件布局，确认上下区域约各占一半，日志框为只读多行且可复制。
3. 实际发送 HOME，确认界面状态和日志同时从关闭变为开启，再次发送恢复关闭。
4. 同步开启后实际按下普通按键、组合键、鼠标移动/按钮/滚轮；逐项对比本机是否无动作、对端是否收到对应报告。
5. 实际发送 END、关闭窗口和模拟异常退出，确认鼠标裁剪解除、键盘/鼠标按键释放、对端收到 `ReleaseAll`。
6. 保留测试输入、期望报告、实际报告、窗口截图或控件读取结果和进程退出状态；启动成功或退出码为 0 不能单独算通过。

## 技术债记录

- `host/HidBridge.Host`：尚无托盘窗口和配置页；当前运行状态集中在主窗体日志栏。
- `host/HidBridge.Host/Transport/SerialBridge.cs`：自动发现缺少设备类型过滤、扫描缓存和可配置探测超时。
- `tests`：缺少统一测试项目/覆盖率收集和真实硬件结果归档机制。
- `firmware/main/output_router.c`：输出锁定、Wi-Fi 输出和 BLE/USB 生命周期需要进一步拆分并补充集成测试。
- `firmware/main/idf_component.yml`：使用 `espressif/led_strip ^3.0.3`，应在后续 ESP-IDF 升级时重新验证 API 和依赖锁文件。
- 串口协议 v2 在本地 USB 链路上不做身份认证；当前安全边界依赖用户明确连接的本机串口，不能扩展为不可信网络控制协议。
