# 项目审计

更新时间：2026-09-20

## 审计口径

- 本轮右键误松开修复使用记录传输和两个模拟 Raw Input 设备句柄，不调用真实 `SendInput`，不能替代真实多设备和被控机验收。
- 本轮 kmboxNet 兼容验证只使用 Loopback UDP、RecordingTransport 和离屏 WinForms 布局，不调用真实 `SendInput`，不作为物理鼠标、目标 HID 或原始 `.pyd` 端到端验收。
- 本文只保留当前结论、必要证据和未验证风险；旧版本哈希、重复验收和过期运行细节不再重复记录。
- `Pass` 按证据层级解释：源码/构建、自动化 UI/纯逻辑、用户人工验收、真实设备/目标端分别记录，不能合并成全链路通过。
- 本轮已运行 Host publish/Release 编译、完整 Host Checks、Host/Checks 格式检查、固件纯 C 测试、ESP-IDF 构建，并在对端 `192.168.3.50` 通过设置页所选 `COM3` 执行真实刷写；另按用户授权完成可逆的真实 UDP 鼠标采样。GitHub Actions `v0.1.0` 发布资产仍属于上一发布版本。

## 技术债

- BLE 日志缺少中心端地址、每轮广播、连接、加密、HID 就绪和断线原因的可关联时间线。
- `firmware/cmake/nimble_gap_peripheral_connect_compat.cmake` 依赖 ESP-IDF 6.0.2 源码锚点，升级 SDK 时需重新审查。
- 局域网刷写 API 已扩大到所有网卡监听，但仍是轻量 TCP/HTTP 实现；后续若面向非受信任网络，需要认证、TLS、请求限流和更严格的来源授权。
- 仓库未配置 Lint 和覆盖率；质量结论依赖构建、Format、专项检查和分层验收。
