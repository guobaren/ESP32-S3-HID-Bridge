## Known Issues

- `host/HidBridge.Host/Input/InputForwarder.cs:320`：X/Y 分别限幅会在单轴先耗尽时改变大位移的中间方向。
- `host/HidBridge.Host/Input/RawMouseInputWindow.cs:101`：每个 Raw Input 事件立即进入发送路径，没有可用于曲线拟合的历史窗口或已知终点。
- `firmware/main/hid_output.c:17`：USB HID 队列固定为 32 项。
- `firmware/main/hid_output.c:201`：队列满时零等待返回 `ESP_ERR_TIMEOUT`；主机端没有背压或重试，密集曲线采样可能丢帧。
- `firmware/main/input_session.c:80`：固件仅记录输出丢帧，无法把拥塞反馈给主机轨迹调度器。
- `target/HidBridge.TargetAgent/WindowsInputInjector.cs:83`：Target Agent 使用相对 `SendInput`；目标 Windows 的鼠标速度和加速设置会影响分段后的屏幕位移。
