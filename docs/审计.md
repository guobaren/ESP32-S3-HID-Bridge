## Known Issues

- `firmware/main/usb_output_liveness.h:13`、`firmware/main/hid_output.c:638-662` 没有独立 native-USB VBUS 检测，USB 初始状态仍依赖 3000 ms 宽限期。
- `host/HidBridge.Host/LogFileRetention.cs`、`host/HidBridge.Host/Ui/UiLogTextWriter.cs`：日志首次创建目录、数量超限清理和分析图 PNG 尚未运行时验证。
- `host/HidBridge.Host` 与接收目标之间没有 HID 报告应用回读，无法仅凭 Host/固件传输证明目标窗口实际消费报告。
- `host/HidBridge.Host/Ui/MouseMovementAnalysisForm.cs:22-27`、`host/HidBridge.Host/Ui/SettingsPageControl.cs:52-58`：分析图路径已实现，但实际 PNG 生成和用户已有配置覆盖行为未验证。
- `D:\ESP32-S3-HID-Bridge-worktrees\input-latency-telemetry` 是受保护且登记为 `prunable` 的 worktree，不能删除或重置。

## 技术债

- BLE 日志缺少中心端地址、每轮广播、连接、加密、HID 就绪和断线原因的可关联时间线。
- `firmware/cmake/nimble_gap_peripheral_connect_compat.cmake` 依赖 ESP-IDF 6.0.2 源码锚点，升级 SDK 时需重新审查。
- 本机刷写 API 只允许 Loopback；若扩大到网络或上传场景，需要更成熟的服务器和权限模型。
- 仓库未配置 Lint 和覆盖率；质量结论依赖构建、Format、专项检查和分层验收。
