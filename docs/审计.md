## Known Issues

- `host/HidBridge.Host/RemoteInput/RemoteInputServer.cs:42-54`：UDP 监听没有身份认证；MAC 和来源端点只用于协议会话匹配，不构成安全认证，只应部署在受信任局域网。
- `host/HidBridge.Host/RemoteInput/RemoteInputServer.cs:139-229`：`reboot/setconfig/setvidpid/lcd` 按当前需求不支持且不执行；如后续开放，需要单独确定设备控制语义和权限边界。
- `tests/HidBridge.Host.Checks/Program.cs:1605-1700`：专项检查按参考源码构造 kmboxNet 报文，尚未用原始 Python `.pyd` 做真实端到端调用。

## 技术债

- BLE 日志缺少中心端地址、每轮广播、连接、加密、HID 就绪和断线原因的可关联时间线。
- `firmware/cmake/nimble_gap_peripheral_connect_compat.cmake` 依赖 ESP-IDF 6.0.2 源码锚点，升级 SDK 时需重新审查。
- 本机刷写 API 只允许 Loopback；若扩大到网络或上传场景，需要更成熟的服务器和权限模型。
- 仓库未配置 Lint 和覆盖率；质量结论依赖构建、Format、专项检查和分层验收。
