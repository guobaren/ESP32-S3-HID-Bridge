- `host/HidBridge.Host/RemoteInput/RemoteInputServer.cs:69` 对每个无效 UDP 数据报逐条记录；若异常发送持续存在会造成日志刷屏，后续可在不放宽协议校验的前提下增加同类错误限流。
- `host/HidBridge.Host/Input/MouseReportPump.cs` 的统计输出已与 500 Hz 实时线程隔离；真实鼠标捕获复测完成前，不将自动化节拍结果替代为设备链路验收。
- `host/HidBridge.Host/Ui/LuaPageControl.cs` 已通过构建和自动化检查，但真实滚动性能及系统剪贴板多来源粘贴仍需新版 UI 实测。
- `host/HidBridge.Host/Input/InputForwarder.cs` 仅放行注入 F13–F24；若具体外设驱动不使用标准 `VK_F13..VK_F24`，仍需采集其实际 `VirtualKey/Flags` 后适配，不能仅凭静态映射判定真实设备通过。
